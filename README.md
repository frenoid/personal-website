## How to deploy
This website is deployed using AWS Amplify using manually deployments

### Steps to deploy
1. Go to [AWS Amplify App Page](https://ap-southeast-1.console.aws.amazon.com/amplify/apps/d30vkfxoz9ztim/overview)
2. Click on `Deploy updates`
3. Click on `Amazon S3`
4. Enter `s3://normanlimxk.com/` into the field `S3 location of objects to host`
5. Clikc on `Save and deploy`
